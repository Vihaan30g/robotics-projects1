Robotic Manipulation Projects

A repository of five ROS 2 workspaces covering the main layers of manipulator software: collision-free motion planning, reaching a goal pose, real-time Cartesian control with MoveIt 2 Servo, and a complete autonomous task for the Caterpillar Autonomy Challenge.

1. Overview

This repository collects my work on robotic manipulation. Each folder is an independent ROS 2 workspace (prefixed ws_) built around one specific capability, so you can open any one of them without needing the others.

Together they follow a natural progression: first planning a safe path with MoveIt 2, then commanding the arm to a target pose, then controlling it live in Cartesian space, and finally putting these pieces to work on a real competition task.

4. How the projects fit together

The projects build on the same ideas at increasing levels of complexity:

 PLAN a safe path          ws_moveit_pathplan
        |
        v
 REACH a target pose       ws_goalpose_moveit
        |
        v
 CONTROL live in space     ws_IRC_2dof_cartesian
                           ws_IRC_5dof_cartesian
        |
        v
 DO a full task            ws_caterpillar_auto_final
Two ways of moving an arm. The planning projects compute a complete trajectory first and then execute it. The Servo projects work differently: they take a continuous stream of Cartesian commands and turn them into joint motion in real time, which suits teleoperation and fine adjustment.

5. Getting the code

Clone the repository, then enter the workspace you are interested in:

git clone https://github.com/Vihaan30g/robotics-projects1.git
cd robotics-projects1/ws_moveit_pathplan

Each workspace is a standard ROS 2 workspace, so after installing its dependencies it is built with colcon build and sourced with source install/setup.bash. Check the files inside each folder for its specific launch instructions.
